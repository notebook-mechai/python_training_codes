تبدیل یک پوشه معمولی به یک مخزن گیت (شروع پروژه).
git init


نمایش وضعیت فعلی (کدام فایل‌ها تغییر کرده‌اند و آماده ثبت هستند).
git status


آماده‌سازی تمام فایل‌های تغییرکرده برای ثبت (مرحله‌بندی).
اگر در آخر این دستور دات قرار دهید یعنی تمامی فایل هایی که مستلزم تغییرات شده اند
و اگر فقط اسم یک   یا چندین فایل نوشته شوند یعنی فقط آنها  می توانند به 
مخزن افزوده شوند
git add .
git add abstraction_car_class.ipynb


ثبت نهایی تغییرات همراه با یک پیام توضیحی.
git commit -m "پیام"

ارسال کامیت‌های محلی به مخزن دوردست (مثل GitHub).
git push


دریافت آخرین تغییرات از مخزن دوردست و ادغام آن‌ها با کد شما.
git pull
